# whoami deliverables

Every format below follows the evidence rules and ⚠ marking in `SKILL.md`; only the shape changes.

## 研究基础 section

Organised by the confirmed themes, one subsection each. Under each theme: what the user has done (achievements with provenance), what it established, and how it leads into the proposed work. Close with the paper count and list from the step 1 inventory, filtered as the call for proposals asks (for example, the last five years), stating the filter. Ask the user for the target length and the call's own headings before drafting; use their headings when given.

## 报告选题与摘要

Ask the user for the audience, venue and length. Run steps 1–4 on the talk's topic instead of the whole direction. Offer 2–3 candidate titles, each with one line on the angle, then an abstract for the one the user picks. Achievements in the abstract carry provenance like any draft; the talk's forward-looking part is written as outlook, not as results.

## Form fields

Ask the user for the form's fields and their limits (characters, item counts). Fill the fields in the form's order. 代表性成果 lists achievements only, so ⚠ items stay out of it and go in the ⚠ list below the draft. 项目清单 comes from the authoritative project and award list when Identity has one, and from the workflow below when it does not.

## Project and award list

The authoritative list is a source the user adds to Identity by hand; once it is there, it is the only basis for projects and awards. Look for it in the step 1 inventory first.

When Identity has none:

1. From the inventory, pick the most recent application by its title and confirm the choice with the user.
2. Read its project and award status lines with `source search -s <source_id>` (terms such as 在研, 结题, 主持, 获奖).
3. Draft one row per status line: category, name, grant number, years, the user's role, status, and the line's `cited_text`. Lines from the application's plan or targets are not rows.
4. Hand the draft to the user to revise and add to Identity as their own source. The agent's part ends at the hand-off.

Papers need no maintained list: titles already give it.
